Privacy Policy – Pofuland Uploader

Effective date: 17 October 2026

Pofuland Uploader ("the tool") is a private desktop application used only by the owner of the Pofuland YouTube channels (@pofulandkids and @pofulandtr) to upload their own videos. The tool uses YouTube API Services.

By using the tool you agree to be bound by the YouTube Terms of Service: https://www.youtube.com/t/terms
Google Privacy Policy: https://policies.google.com/privacy

1. What data the tool accesses

The tool asks Google for permission (OAuth 2.0) only to:
• upload videos and thumbnails to the authorized channel (youtube.upload scope), and
• read the authorized channel's basic information (channel ID, title, handle) to confirm the correct channel before uploading (youtube.readonly scope).
The tool does not access any other YouTube or Google account data, and it does not access data of any viewer or other user.

2. How the data is used

The data is used only to upload the owner's own videos to the owner's own channels and to confirm the target channel.

3. Storage

OAuth tokens are stored only on the owner's own computer, in a private file readable only by the owner. Nothing is stored on any server. No data is collected, sold, shared with or disclosed to any third party.

4. Cookies and tracking

The tool does not use cookies, analytics or any tracking technology.

5. Revoking access

Access can be revoked at any time at https://security.google.com/settings/security/permissions. Deleting the local token files also removes all stored data.

6. Compliance

The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
